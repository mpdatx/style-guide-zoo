# Overview

style-guide-zoo applies a collection of prose style guides — each written as a
Claude system prompt — to a shared corpus of passages, several runs each, and
publishes the outputs side by side with the complete provenance of every
generation. All generation happens locally through the Claude Code CLI and is
committed; nothing is generated in CI or in the browser.

The project is built and working. The full matrix is ten guides × nine passages
× five runs = 450 committed records, every cell populated, no failures. The
repository is public and the site is served by GitHub Pages at
https://mpdatx.github.io/style-guide-zoo/.

## About these docs

Markdown in `docs/` is the source. `docs/site/` and `docs/roadmap.md` are generated by
`uv run scripts/pmdocs.py build` — the pre-commit hook does this for you — and are never
edited by hand. `docs/pmdocs.toml` maps source files to the pages that describe them.
Ad-hoc ideas go in `TODO.md` at the repository root; they are triaged into the backlog.

Note that two directories are called "site" and they are unrelated:
`site/` at the root is the published style-guide-zoo application that
`.github/workflows/pages.yml` deploys, while `docs/site/` is this documentation
rendered to HTML.
