Style Guide Zoo

What does a style guide actually do to a piece of writing? Pick a style to see it applied across every source, or pick a source to compare two voices on it side by side. Every output was generated locally with the Claude Code CLI and committed; expand any output to see the exact prompt, model, and token usage behind it.

Outputs are generated by Claude and are not human-written. Runs are not bit-reproducible: the CLI does not expose a temperature or sampling seed, which is why several runs of each combination are published.
